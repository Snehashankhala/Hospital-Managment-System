# Hospital Management System (Java + MySQL)
Java Project with JDBC

This is a simple console-based Hospital Management System built with Java and MySQL.  
Users can add patients, view patients and doctors, and book appointments.


## 📌 Features

✔ Add new patients  
✔ View all patients  
✔ View all doctors  
✔ Book an appointment with a doctor  
✔ Checks for doctor availability  
✔ Uses JDBC for database connectivity

## 📦 Requirements

✔ Java JDK 8 or above  
✔ MySQL Server  
✔ MySQL Connector/J (JDBC driver)  
✔ IntelliJ IDEA (or any Java IDE)
